# Exchange Service - Конвертация валют

Этот сервис обеспечивает получение курса валют от Центрального банка Узбекистана и конвертацию USD в UZS для отчетов.

## Настройка

### 1. Переменные окружения

Добавьте в ваш `.env` файл:

```env
USD_STORAGE_ID=123
```

Где `123` - это ID склада/счета, который является валютным (USD).

### 2. API Endpoints

- `GET /exchange/usd` - Получить текущий курс USD к UZS
- `GET /exchange/test-conversion` - Тест конвертации 100 USD в UZS
- `GET /exchange/status` - Проверить доступность API ЦБ Узбекистана

### 3. Как это работает

1. Система определяет валютный счет по переменной `USD_STORAGE_ID`
2. При расчете остатков по счету S50 (денежные средства) проверяется, является ли счет валютным
3. Если счет валютный, система:
   - Получает остатки в USD через `TypeQuery.POUSD` и `TypeQuery.KOUSD`
   - Конвертирует их в UZS по курсу ЦБ Узбекистана
   - Добавляет конвертированные суммы к основным остаткам в сумах

### 4. Источник курса валют

Используется официальный API Центрального банка Узбекистана:
- URL: `https://cbu.uz/uz/arkhiv-kursov-valyut/json/`
- Формат данных: JSON массив с объектами валют
- Обновление: каждый банковский день в 16:00 по ташкентскому времени

Структура ответа API:
```json
[
  {
    "id": 69,
    "Code": "840",
    "Ccy": "USD",
    "CcyNm_RU": "Доллар США",
    "CcyNm_UZ": "AQSH dollari",
    "CcyNm_UZC": "АҚШ доллари",
    "CcyNm_EN": "US Dollar",
    "Nominal": "1",
    "Rate": "12099.72",
    "Diff": "15.62",
    "Date": "03.10.2025"
  }
]
```

### 5. Обработка ошибок

- При недоступности API ЦБ система использует только остатки в сумах
- Детальные ошибки логируются в консоль с эмодзи для удобства
- Система продолжает работать даже при сбоях конвертации
- Добавлен endpoint `/exchange/status` для проверки доступности API

### 6. Логирование

Система выводит подробные логи:
- ✅ Успешная конвертация валют
- ❌ Ошибки получения курса
- ⚠️ Предупреждения о fallback на сумы
- 💡 Подсказки по диагностике проблем

## Интеграция в отчеты

Сервис автоматически интегрирован в отчет `DebitorKreditor` и будет применяться ко всем валютным счетам, определенным через `USD_STORAGE_ID`.
