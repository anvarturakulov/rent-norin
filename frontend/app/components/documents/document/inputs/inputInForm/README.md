# InputInForm Component - Оптимизации

## Обзор оптимизаций

Компонент `InputInForm` был полностью переработан для улучшения производительности, читаемости и поддерживаемости кода.

## Ключевые улучшения

### 1. Разделение ответственности
- **Кастомный хук `useInputFormData`**: Выносит логику работы с данными
- **Компонент `FormInput`**: Мемоизированный компонент для инпута
- **Константы**: Вынесены в отдельный файл для переиспользования

### 2. Мемоизация данных
- **useMemo для текущего значения**: Кэширует значение инпута
- **useCallback для обработчиков**: Предотвращает лишние ре-рендеры
- **React.memo для компонента**: Оптимизирует рендеринг

### 3. Улучшенная структура
- **Константы**: Вынесены в отдельный файл
- **Разделение логики**: Каждая функция отвечает за одну задачу
- **Типизация**: Улучшенная типизация интерфейсов

### 4. Автоматические вычисления
- **Автоматический расчет total**: При изменении count или price
- **Точность вычислений**: Фиксированная точность для разных полей
- **Валидация**: Проверка минимальных значений

## Структура файлов

```
inputInForm/
├── inputInForm.tsx                 # Основной компонент
├── components/
│   └── FormInput.tsx               # Мемоизированный инпут
├── constants/
│   └── inputForm.constants.ts      # Константы для типов полей
├── hooks/
│   └── useInputFormData.ts         # Кастомный хук для работы с данными
└── inputInForm.props.tsx           # Типы пропсов
```

## Использование

### Базовое использование
```tsx
<InputInForm
  nameControl="count"
  label="Количество"
  visible={true}
/>
```
