# CheckBoxInTable Component - Оптимизации

## Обзор оптимизаций

Компонент `CheckBoxInTable` был полностью переработан для улучшения производительности, читаемости и поддерживаемости кода.

## Ключевые улучшения

### 1. Разделение ответственности
- **Кастомный хук `useCheckboxData`**: Выносит логику работы с данными
- **Компонент `CheckboxInput`**: Мемоизированный компонент для чекбокса
- **Константы**: Вынесены в отдельный файл для переиспользования

### 2. Мемоизация данных
- **useMemo для текущего значения**: Кэширует состояние чекбокса
- **useCallback для обработчиков**: Предотвращает лишние ре-рендеры
- **React.memo для компонента**: Оптимизирует рендеринг

### 3. Улучшенная структура
- **Константы**: Вынесены в отдельный файл
- **Разделение логики**: Каждая функция отвечает за одну задачу
- **Типизация**: Улучшенная типизация интерфейсов

### 4. Взаимно исключающая логика
- **Автоматическое отключение**: При включении одного чекбокса отключаются другие
- **Группировка**: Логические группы чекбоксов
- **Безопасная обработка**: Проверки на null/undefined

- **Время загрузки**: Улучшено за счет мемоизации
- **Память**: Более эффективное использование
- **UX**: Плавный интерфейс без задержек

## Функциональность

### Взаимно исключающие чекбоксы
- `partner` - отключает `worker` и `founder`
- `worker` - отключает `partner` и `founder`
- `founder` - отключает `partner` и `worker`

### Поддерживаемые типы
- `partner` - партнер
- `worker` - работник
- `founder` - учредитель
- `proveden` - проведен
- `cash` - наличные
- `orderWithDeleviry` - заказ с доставкой

### Мемоизация
- Значения кэшируются между рендерами
- Обработчики событий не пересоздаются
- Компонент ре-рендерится только при изменении данных

### Безопасность
- Проверки на существование данных
- Безопасная обработка null/undefined
- Типизация предотвращает ошибки

## Константы

### CHECKBOX_TYPES
Определяет все возможные типы чекбоксов

### CHECKBOX_PROPERTIES
Связывает тип чекбокса с соответствующим свойством в docValues

### MUTUALLY_EXCLUSIVE_GROUPS
Определяет группы взаимно исключающих чекбоксов
